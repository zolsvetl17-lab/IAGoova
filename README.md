## Описание

Random Task Generator — это простое графическое приложение (GUI), которое помогает генерировать случайные задачи из предопределённого списка. Программа позволяет:

* генерировать случайную задачу по нажатию кнопки;
* просматривать историю сгенерированных задач;
* фильтровать историю по типам задач (учёба, работа, спорт, отдых);
* добавлять новые задачи в общий список;
* сохранять историю задач между запусками приложения (в формате JSON).

## Функционал

* **Генерация задач.** Кнопка «Сгенерировать задачу» выбирает случайную задачу из списка и отображает её.
* **История задач.** Все сгенерированные задачи сохраняются и отображаются в списке.
* **Фильтрация.** Возможность фильтровать историю задач по типам: учёба, работа, спорт, отдых (и «все»).
* **Добавление задач.** Пользователь может добавлять свои задачи с указанием типа.
* **Валидация ввода.** Проверка на пустую строку при добавлении новой задачи.
* **Сохранение данных.** История и список задач сохраняются в файле `tasks.json` и загружаются при следующем запуске.

## Установка и запуск

### Требования

* Python 3.6 или выше;
* стандартные библиотеки: `tkinter`, `random`, `json`, `os`.

   git clone https://github.com/zolsvetl17-lab/IAGoova.git
   cd RandomTaskGenerator
2. Запустите приложение:
   ```bash
   python main.py
### Использование
1. **Сгенерировать задачу.** Нажмите кнопку «Сгенерировать задачу», чтобы получить случайную задачу. Она отобразится вверху окна и добавится в историю.

2. **Просмотреть историю.** Список всех сгенерированных задач отображается в нижней части окна.

3. **Отфильтровать задачи.** Используйте выпадающий список «Фильтр» для отображения задач определённого типа.

4. **Добавить новую задачу.** Введите текст задачи в поле ввода, выберите тип из выпадающего списка и нажмите «Добавить в список».

5. **Закрыть приложение.** Просто закройте окно — данные автоматически сохранятся в tasks.json.
