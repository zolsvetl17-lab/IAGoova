# Weather Diary

**Автор:** Гоова Инна

## Описание

Приложение для ведения дневника погоды, позволяющее добавлять, просматривать и фильтровать записи о погоде с сохранением данных в JSON‑файл.

## Функциональность

* Добавление записей о погоде с указанием даты, температуры, описания и наличия осадков.
* Просмотр всех записей в табличном виде.
* Фильтрация записей:
  * по дате;
  * по температуре (выше/ниже заданного значения).
* Сохранение данных в файл JSON.
* Валидация вводимых данных.
